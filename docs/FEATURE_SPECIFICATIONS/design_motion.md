# Design, Motion & Feedback

## Visual
Apple-quality benchmark without copying Apple. OLED black, black/white tonal surfaces, rich blue/green accent, selective glassmorphism, opacity, ample whitespace, premium grotesk typography and Lucide icons.

Candidate fonts: Hanken Grotesk, Host Grotesk.

## Navigation
Navigation pill transforms between Home/Transactions/Explore and Goals/Categories/Insights. Separate persistent + action.

## Motion
Use purposeful transitions for snapshot swipe/flip, navigation transformation, bottom sheets, goal progress and completion.

## Haptics
Use subtle haptics for meaningful mutations and interactions where supported. Never vibrate on every tap.

## Empty/Error
Typography and icons rather than large illustrations.
