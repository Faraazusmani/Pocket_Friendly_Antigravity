# Insights

Local, deterministic and based only on user financial data.

Filters: month and year.

Must distinguish:

1. Total income
2. Total actual spending (Goal transfers excluded)
3. Goal savings (net transfers into Goals)
4. Account savings
5. Total savings

Other types: savings rate, average daily spend, biggest expense, six-month income/expense/savings trend, top categories, spending spikes, unusual transactions, recurring expenses, category trends, budget risks, Goal risks, month-over-month changes.

No external financial recommendations. No Balance Adjustment in income/spend/savings series.

Privacy Mode applies to all insight values.
