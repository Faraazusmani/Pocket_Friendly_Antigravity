# Dashboard

## Sections
Header → Monthly Snapshot → Safe-to-Spend → Budget warning → Goals → Recent Transactions.

Calculations must come from domain/application services. Do not duplicate accounting in widgets. Multi-currency: per-currency sections, never silent conversion.

## Snapshot
View A: Available Budget hero + Total Monthly Budget support (`AvailableBudget = TotalMonthlyBudget − EligibleSpentToDate`).

View B: Net Available Balance hero + Income/Spent support (`Bank + Cash` only).

Swipe between views with subtle motion.

## Month Selector
Changes only Snapshot context and subtly highlights it. Other dashboard content remains current.

## Privacy
All financial values respect Privacy Mode.
